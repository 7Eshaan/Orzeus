# @orzeus/schema

Zod schemas and inferred types for TaskDAG, ContextPacket, TraceEvent, PlannerOutput and policies. The single source of truth for data shapes.

## Rules

Pure. Depends only on zod. No IO, no Node or DOM APIs.
